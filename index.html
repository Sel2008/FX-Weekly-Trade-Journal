Hard fails: no meaningful HTF level, R:R below 1.5R, arbitrary stop, chasing after displacement, or entry based mainly on prediction.

Core model: 4H/1D tells you WHERE. 1H/15M tells you WHEN.

Short: resistance → compression → rejection → bearish displacement → retest → short → next support.

Long: support → compression → rejection → bullish displacement → retest → long → next resistance.
